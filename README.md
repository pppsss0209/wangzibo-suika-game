# 合成王子博

一个可直接发布到静态网站的手机 / 电脑游戏。玩法参照“合成大奶娃 / 合成大西瓜”：

- 鼠标移动瞄准、点击投放；触屏拖动瞄准、松手投放。
- 左右方向键或 `A` / `D` 微调，空格投放，`R` 重开。
- 两个相同等级的人物头像碰到一起，会合成下一等级。
- 最高等级的两个头像相撞会消失并获得奖励分。
- 当前合成链使用九张照片：初见、伞下、窗边、雨窗、拍照、肖像、窗前、日落、车上看树。
- 伞下照片使用内缩的不规则轮廓，红白标注线不会出现在游戏画面中。
- 头像超过警戒线并停住约 1.5 秒后结束。
- 音效由 Web Audio 实时生成，不依赖外部音效文件。
- 最高分和本机高手榜保存在浏览器本地。
- “分享给好友”支持手机系统分享，也支持复制带成绩参数的挑战链接。

## 本地打开

直接双击 `index.html` 可以试玩。手机分享与安装到桌面建议将整个目录发布到 HTTPS 静态网站。

## 静态托管

整个 `dragon-heads-game` 目录都是纯静态文件，可直接部署到 GitHub Pages、Cloudflare Pages、
Netlify、Vercel 或任意普通网站根目录，不需要构建命令。

发布后，微信里分享网站首页即可。游戏内“分享成绩”会生成类似：

```text
https://你的域名/?from=玩家&score=123
```

好友打开后会看到挑战分数。
